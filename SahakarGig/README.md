## 📌 Overview

**SahakarGig** is a cooperative-owned digital service marketplace designed to connect **verified skilled workers from Labour Cooperative Societies and Federations** with households, communities, and institutions that require reliable services.

The platform enables cooperatives to digitally manage their workforce while providing customers with a trusted way to **discover, book, track, and review skilled service providers**.

Unlike conventional private gig platforms, SahakarGig places the **cooperative and its workers at the center of the ecosystem**, focusing on fair work opportunities, transparent payments, worker welfare, and efficient workforce allocation.

---

## 🎯 Problem Statement

Labour Cooperative Federations and Labour Cooperative Societies have a large pool of skilled workers, including:

* ⚡ Electricians
* 🔧 Plumbers
* 🪚 Carpenters
* 🎨 Painters
* 🧹 Cleaners
* 🏠 Domestic Helpers
* ❤️ Caregivers
* 🚗 Drivers
* 🌱 Gardeners
* 🛠️ Technicians

However, many cooperatives lack a structured digital platform to connect these workers with customers.

This results in:

* Underutilization of skilled workers
* Irregular employment opportunities
* Difficulty discovering verified workers
* Lack of centralized worker and skill management
* Inefficient workforce allocation
* Limited customer trust
* Poor visibility into service demand
* Lack of integrated worker welfare mechanisms

The system ranks nearby workers based on the matching criteria.

#### Step 3 — Worker

The nearest suitable worker receives:

> 🚨 Emergency Plumbing Request — 1.4 km away



# 🛠️ Setup & Installation

## Prerequisites

Make sure the following are installed:

* **Node.js** 18+
* **npm** 9+
* **Git**
* **Python** 3.10+ *(required for AI/ML services)*
* **PostgreSQL** 14+ *(if using PostgreSQL locally)*

Verify the installations:

```bash
node --version
npm --version
python --version
git --version
```

---

## 1. Clone the Repository

```bash
git clone https://github.com/<YOUR-USERNAME>/SahakarGig.git

cd SahakarGig
```

> Replace `<YOUR-USERNAME>` with the GitHub username that owns the repository.

---

## 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```

The frontend will normally be available at:

```text
http://localhost:3000
```

---

## 3. Install Backend Dependencies

Open another terminal:

```bash
cd SahakarGig/backend
npm install
```

Start the backend:

```bash
npm run dev
```

The API will normally run at:

```text
http://localhost:5000
```

---

## 4. Configure Environment Variables

Create a `.env` file inside the backend directory:

```env
PORT=5000

DATABASE_URL=postgresql://username:password@localhost:5432/sahakargig

JWT_SECRET=your-development-secret

MAPS_API_KEY=your-maps-api-key

PAYMENT_API_KEY=your-payment-api-key

AI_SERVICE_URL=http://localhost:8000
```

### Important

Never commit `.env` to GitHub.

Add this to `.gitignore`:

```gitignore
.env
.env.local
node_modules/
__pycache__/
*.pyc
```

Provide a safe template as:

```text
.env.example
```

Example:

```env
PORT=
DATABASE_URL=
JWT_SECRET=
MAPS_API_KEY=
PAYMENT_API_KEY=
AI_SERVICE_URL=
```

# ⚠️ Troubleshooting

### Port already in use

If port `3000` or `5000` is already occupied, change the corresponding port.

```env
PORT=5001
```

### Database connection failed

Check:

```text
✓ PostgreSQL is running
✓ Database exists
✓ Username/password are correct
✓ DATABASE_URL is correct
```

### AI service unavailable

Check that the Python service is running:

```bash
python app.py
```

Then verify:

```text
http://localhost:8000/health
```

### Map not loading

Check that:

* The maps API key is configured
* The required map/geolocation APIs are enabled
* The key is not restricted incorrectly

# 🎤 SIH Presentation Demo Order

For a **5–7 minute SIH demonstration**, the recommended order is:

```text
1. Problem
      ↓
2. Customer creates emergency request
      ↓
3. Geo-based matching finds workers
      ↓
4. Customer books worker
      ↓
5. Worker accepts request
      ↓
6. Service is completed
      ↓
7. Payment + invoice
      ↓
8. Customer rates worker
      ↓
9. Cooperative dashboard updates
      ↓
10. AI forecasts future demand
      ↓
11. AI recommends workforce allocation
```

This demonstrates the complete **Customer → Worker → Cooperative → AI** ecosystem rather than just showing individual UI screens.
